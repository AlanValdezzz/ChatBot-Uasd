## Uso de Inteligencia Artificial
Se utilizó Gemini como inteligencia artificial principal y su API. También se usó para arreglar errores, mejorar el CSS y resumir el PDF del Estatuto Orgánico de la UASD.

## Antes de usarlo
Para que el código funcione, hay que abrir el archivo "config.js" y pegar su propia API key de Google AI Studio.
